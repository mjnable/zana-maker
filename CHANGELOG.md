# Changelog

All Zana packages share one version number and are released together. A release that did
not change this package is not listed.

## 2.19.2 — Unreleased

### Security

- `AGENTS.md` says that templates do not escape objects, that a URL from users needs its scheme checked, and how
  to store uploads.

## 2.19.0 — 2026-11-07

### Changed

- `make:agents`: `AGENTS.md` asks agents for a security check on risky changes, and to report it in their
  summary (FE-67).

## 2.11.0 — 2026-11-01

### Added

- `make:plan <file.json>`: a module, its entities, value objects, repositories and features from one
  plan file (`zana.plan/1`), generated by the same `make:` commands in a temporary copy first, so
  nothing is written unless every step succeeds (FE-51, ADR-026).
- `agents.instructions` in `check`: a warning when `AGENTS.md` is missing or names another Zana version
  (FE-52).

### Changed

- `make:agents` writes the commands with the console script it was run with (FE-54), and `AGENTS.md`
  names `make:plan`.
- Requires `mj-zana/core` ^2.11.

## 2.8.0 — 2026-11-01

### Added

- Whole use cases (FE-47):
  - `make:feature … --field=name:type` gives the command or query typed properties (`string`, `int`,
    `float`, `bool`; `?type` optional); a required string gets `#[NotBlank]`;
  - `make:feature … --http` adds the vertical slice: an API action routed to
    `POST /api/<module>/<feature>` (`GET` for a query), the module's `ApiInput` (JSON or query string →
    a validated command or query; 400 or 422 with the field errors), and an HTTP test;
  - `make:value-object <Module> <Name> [--type=string|int|float]`: a value object with an example rule,
    and its test;
  - `make:repository <Module> <Entity>`: the database implementation of the entity's repository
    interface, with optimistic versions, its migration and its registration.
- `--format=json` on every `make:` command: the files, the wiring lines and the manual steps
  (`zana.make/1`).
- Manual steps name the providers missing from `src/Bootstrap.php`, and the commands name the packages
  the generated code needs.
- `AGENTS.md` describes the new commands and plans with `--dry-run --format=json` (FE-49).

### Changed

- `make:entity` writes `restore(<Entity>Id $id, int $version)`, used by the generated repository.
- The generated handler tests construct the command or query with example values for its fields.
- Generated files always have LF line endings, whatever line endings Git gave the stubs.
- The module stub's marker comments say that every `make:` command adds lines above them.

## 2.7.0 — 2026-10-31

### Added

- `make:agents [--zana-version] [--force]`: writes `AGENTS.md`, the rules and workflow of a Zana
  application for AI coding agents, linked to the documentation of the installed Zana version, with
  `CLAUDE.md` and `.github/copilot-instructions.md` pointing to it (FE-44).

### Changed

- Requires `mj-zana/core` and `mj-zana/console` ^2.7.

## 2.4.0 — 2026-10-26

### Changed

- Factory registrations declare the services they resolve with `uses()`, so the container checks
  their lifetimes at startup (FE-40).
- Requires `mj-zana/core` ^2.4.

## 2.3.0 — 2026-10-26

### Changed

- Tests and tooling (`tests/`, `phpunit.xml.dist`, `phpstan.neon.dist`) are no longer in Composer
  archives, so they stay out of production `vendor/` folders (FE-17).

## 2.2.0 — 2026-10-26

### Added

- `make:crud`: back-office screens for a content type, in one or every locale (`--translatable`):
  list, create, edit, publish, archive, delete after confirming, and a signed preview link
  (FE-32).
- `make:page`: a localised page with its routes, metadata and template (FE-16).
- `--web` on `make:module` and `make:controller`: HTML controllers and templates (FE-16).

## 2.0.0 — 2026-10-26

The final 2.0 release. No changes since 2.0.0-rc.1.

## 2.0.0-beta.3 — 2026-10-25

### Added

- Generated code is wired into the module class (`// zana:maker services` and `// zana:maker boot`
  markers); `Generator::manualSteps()` lists what could not be wired, and the commands print it.

## 2.0.0-alpha.3 — 2026-10-24

First release of the 2.0 line. Code generators that follow the Zana module layout. Conventions produce plain, explicit code you own, not runtime magic. Requires PHP 8.5 or later.

Documentation: [the maker guide](https://github.com/mjnable/zana-docs/blob/main/guides/maker.md).
